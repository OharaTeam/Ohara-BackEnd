<objective>
Implementar a paginação de comentários para postagens e refatorar o endpoint detalhado do post para prevenir gargalos de desempenho e vazamento de payloads não limitados (Issue #11 / TASK-02).

Purpose: Garantir a escalabilidade da plataforma Ohara impedindo o carregamento irrestrito de comentários em `getPost`, substituindo-o por `_count.comentarios`, e fornecendo um endpoint dedicado `GET /postagens/:id/comentarios` com paginação ordenada e enriquecimento de dados públicos do autor.
Output: DTOs `QueryCommentDto` e `CommentResponseDto`, método `getComments` no `PostagensService`, rota `GET :id/comentarios` no `PostagensController`, e cobertura total com testes unitários.
</objective>

       @ApiOperation({
         summary: 'Listar comentários paginados de uma postagem',
         description:
           'Retorna a lista paginada de comentários associados a uma postagem com dados públicos dos autores e contagem total.',
       })
       @ApiParam({
         name: 'id',
         description: 'ID (UUID) da postagem',

       })
       @ApiResponse({
         status: 200,

         type: PaginatedCommentsResponseDto,
       })
       @ApiResponse({
         status: 400,
         description: 'Parâmetros de paginação inválidos.',
       })
       @ApiResponse({
         status: 404,
         description: 'Postagem não encontrada.',
       })
       getComments(
         @Param('id') id: string,
         @Query() query: QueryCommentDto,

         this.logger.log(
           `Solicitação de comentários do post ${id}: página ${query.page || 1}, limite ${query.limit || 5}, ordem ${query.order || 'asc'}`,

         return this.postagensService.getComments(id, query);
       }
